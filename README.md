# JBS YouTube サムネイル作成ツール

JBSの大会・配信用YouTubeサムネイルをブラウザ上で作成するツールです。

公開ページ：  
https://jbsbackgammon.github.io/thumbnail/

## 基本的な使い方

1. 大会情報を入力します。
   - ヘッダー
   - 回次等
   - 大会名
   - 試合名
   - フッター
2. 左選手・右選手を設定します。
3. 必要に応じて背景写真、テーマカラー、サブカラーを調整します。
4. 画面下のプレビューで仕上がりを確認します。
5. **PNG出力** を押すと、YouTubeサムネイル用の画像を保存できます。

大会名・試合名・選手名は **選択** ボタンから候補を呼び出せます。候補を選ぶと、右側の入力欄へ内容が反映されます。入力欄はそのまま手入力で変更することもできます。

## 大会情報

初期表示は **日本選手権・決勝** です。

大会名を候補から選ぶと、登録されている大会情報に応じて回次等・テーマカラー・サブカラーが反映されます。回次等はJBS共通データの現在値を使用します。

オープン大会は、入力欄では「東京オープン」などの大会名として扱い、サムネイル上では「オープン」の文字を小さく表示します。

試合名の右側にある小さい入力欄には、試合名に付け加えて小さく表示したい文字を入力できます。

## 選手

左選手・右選手の **選択** ボタンから登録済み選手を選べます。

選手を選択すると、選手名・英語名・登録写真が反映されます。写真部分をクリックすると、そのサムネイルだけ別の写真へ変更できます。

## 背景写真

背景写真は次の3種類から選択できます。

- **なし**：通常のサムネイル
- **あり（顔写真表示）**：背景写真を使用し、左右選手の顔写真も表示
- **あり（顔写真非表示）**：背景写真を使用し、左右選手の顔写真は非表示

背景写真を使用する場合は、写真選択後に左右位置・上下位置・拡大縮小・暗さを調整できます。

## カラー

**テーマカラー** と **サブカラー** を変更できます。

大会名を候補から選択した場合は、その大会に登録されているカラーが自動で反映されます。カラーピッカーまたはカラーコードを直接編集して変更することもできます。

## 設定の保存・呼出

画面上部のボタンから設定を保存・再利用できます。

- **設定呼出**：保存済み設定の一覧を表示し、選択した設定を呼び出します。
- **設定保存**：現在の入力内容を保存します。保存に成功すると、ボタンが一時的に「保存完了」と表示されます。
- **JSON取込**：以前にJSON出力した設定ファイルを読み込みます。
- **JSON出力**：現在の設定をJSONファイルとして保存します。

JSONには大会情報、選手名、カラー、背景位置などの設定値が保存されます。アップロードした写真ファイルそのものはJSONには含まれません。

## PNG出力

**PNG出力** を押すと、現在のプレビュー内容を **1920×1080px** のPNG画像として保存します。

保存したPNGは、そのままYouTubeサムネイルとして使用できます。
